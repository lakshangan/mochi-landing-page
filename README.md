# Mochi Landing Page

Official landing page for **Mochi** — The tiny desktop companion that lives on your screen.

## 🚀 Live Demo & Usage

Open `index.html` in any modern web browser or deploy to GitHub Pages / Vercel / Netlify.

## ✨ Features

- **Cross-Platform Download Hub**: Intelligent OS auto-detection for macOS (Apple Silicon & Intel), Windows, and Linux
- **Interactive 3D Mochi character**: Three.js & Canvas LED face rendering with eye tracking and poke reactions
- **Feature showcase & interactive face previewer**: Test facial moods, beads, and animations live in browser
- **Package Integrity & Verification**: Built-in modal with SHA-512 cryptographic verification hashes for all 10 release assets
- **Privacy-first design**: 100% offline-ready, no accounts, zero telemetry
