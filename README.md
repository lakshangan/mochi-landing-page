# Mochi Landing Page

Official landing page for **Mochi** — The desktop companion that lives in your menu bar.

## 🚀 Live Demo & Usage

Open `index.html` in any modern web browser or deploy to GitHub Pages / Vercel / Netlify.

## ✨ Features

- Interactive 3D Mochi character using Three.js & Canvas LED face rendering
- Feature showcase, interactive face previewer, and privacy-first design
- Fully responsive modern toy-box aesthetic
